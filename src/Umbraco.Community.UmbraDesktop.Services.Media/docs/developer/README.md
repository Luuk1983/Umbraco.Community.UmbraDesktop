# Developer guide

How to work with media library files from your own package through the media service.

- [Opening and saving media files](opening-and-saving-media.md): depend on the package, reach its
  context by its alias, open a file, save it back with the check for somebody else's changes, ask
  where a new file goes, and what to do when the service is not there.
- [Optimizing images](optimizing-images.md): resize, convert and strip the metadata of an image file
  you hold, or of media library images in an Optimize images window of their own, and read the report.
