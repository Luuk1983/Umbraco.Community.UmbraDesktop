# Developer guide

How to extend the games in the UmbraDesktop Entertainment Add-on from your own package, and how to
test umbraCoffee. For using them, see the user guide on the [games](../user/games.md) and
[umbraCoffee](../user/umbracoffee.md).

- [Adding a card back or a card face set to Solitaire](solitaire-decks.md): the two manifest types,
  a worked card back and a worked face set, the rules that bit during the build, and a checklist to
  run before you ship.
- [Testing umbraCoffee](umbracoffee-testing.md): console commands that make umbraCoffee act as if an
  episode is upcoming, live, absent or unreachable, for checking the window, the tray cup and the
  reminders.
