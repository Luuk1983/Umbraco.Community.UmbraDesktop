# What you can do with a file

A media item is the record: its name, its fields and where it is used. The picture or document on it
is the file. The item's own page shows the file as its first property, and the tools for the file are
on that page too: **Edit image**, **Download**, **Replace file** and **Optimize**.

They are on the desktop only, for everyone who may use the Media section, and not on items in the
recycle bin.

## Where the tools are

- **Beside Save.** At the bottom of the item's page, the button left of **Save** is **Edit image** on
  an image and **Download** on any other file. Select its arrow for the rest: **Download**,
  **Replace file** and **Optimize** on an image, **Replace file** on another file. A folder has no
  file, so it has no button.
- **On the file itself.** The **...** beside the **Image** or **File** property's name has the same
  tools.
- **In the item's menus.** **Edit image** is also in an image's actions menu (**...**) in the tree, the
  grid and the list. In a Media Manager window it is the button on an image's card.

To open the item's page, select the item in a [Media Manager window](media-manager.md#items) or in the
Media section.

## Edit an image

Select **Edit image**. The [Image Editor](image-editor.md) opens in its own window with the image. If
an editor already has that image open, that window comes to the front instead.

## Download a file

Select **Download**. Your browser saves the file as it is in the media library, under its own name.
Unsaved changes on the page are not in it.

## Replace a file

1. Select the arrow beside **Edit image** or **Download**, then **Replace file**. If the page has
   unsaved changes, you are asked to save them first.
2. Pick the new file on your computer.

The item keeps its name, its fields and every page that uses it, with the new file in place of the
old one. The focal point and crops start again, since they were set on the old picture. The file gets
a new address, so no browser shows the old picture; a link someone pasted to the old file breaks.

A file the item's type does not take is refused, in the words the Media section uses for it: a PDF
cannot go into an image. A large file shows its progress in the
[Transfers](media-manager.md#transfers) window.

## Optimize an image

Select the arrow beside **Edit image**, then **Optimize**. An [Optimize images](optimize-images.md)
window opens for this image, named after it, with the same settings as for many images.
