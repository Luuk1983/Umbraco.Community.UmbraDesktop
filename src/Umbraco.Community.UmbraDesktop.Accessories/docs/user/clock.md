# Clock

Clock is an analogue face with the time and date under it. It writes them the same way as the
taskbar clock: the desktop's **Regional format** and **Clock** settings apply to both. See
[Language and region](https://github.com/Luuk1983/Umbraco.Community.UmbraDesktop/blob/main/docs/user/settings/language-and-region.md).
