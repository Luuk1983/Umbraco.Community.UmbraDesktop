# System Information

System Information is Windows 98's System Properties for the site.

- **General** shows the Umbraco version, the desktop's version and theme, who you are signed in as,
  and the browser and machine you are on.
- **Details** has the rest: the server's own report (operating system, .NET, database), every
  installed package with its version, and your display, memory and processors.

To put all of it on the clipboard for a support request, select **Copy all**.

The server details come from Umbraco's own endpoints, so they show only what your account may see.
Installed packages show only to users with the Packages section.
