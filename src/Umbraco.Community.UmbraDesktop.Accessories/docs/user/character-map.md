# Character Map

Character Map shows characters in a grid by group: accented letters, dashes and quotes, currency,
arrows, maths, box drawing and symbols. Selecting one shows its Unicode name, its code and its
Windows Alt keystroke.

To copy characters:

1. Choose a group, or type a name such as "right arrow", or a code such as "U+2192", in **Search**.
2. Double-click a character, or select it and select **Select**. It is added to **Characters to
   copy**.
3. Select **Copy**. The characters are on the clipboard.

To see the characters in another typeface, choose one in the font list.
