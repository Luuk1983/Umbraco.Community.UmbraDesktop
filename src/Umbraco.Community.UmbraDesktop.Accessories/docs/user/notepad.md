# Notepad

Notepad is a plain-text editor for text files in the media library: `.txt`, Markdown, CSV, JSON,
XML, HTML, CSS, JavaScript and SVG among them. The status bar shows the document's name and the
caret's line and column.

- To start a new document, select **New**.
- To open a text file, select **Open…**. Notepad says so in its status bar if the file is not text.
- To save, select **Save**, or press Ctrl+S.
- To wrap long lines at the window's edge, select **Word wrap**.

Opening and saving work the same way as in Paint. See [Opening and saving files](media-files.md).
