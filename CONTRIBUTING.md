# Contributing

Issues, ideas and pull requests are welcome. For anything bigger than a fix, open an issue first so
we can agree on the shape before you build it.

## Licence of your contribution

Each package in this repository has its own licence, and a contribution comes under the licence of
the package it changes. There is nothing to sign: opening a pull request is agreeing to that.

| Package | Licence |
| --- | --- |
| UmbraDesktop, Entertainment, Accessories, Services.Arcade, Services.Media | [Mozilla Public License 2.0](LICENSE) |
| Media | [FSL-1.1-MIT](src/Umbraco.Community.UmbraDesktop.Media/LICENSE.md) |

Make sure you are allowed to share what you contribute: if you write it for an employer or a client,
check with them first. Code copied from elsewhere must carry a licence that allows it here.

## The Media add-on

Media does not accept pull requests. Issues and ideas for it are welcome.

## Before you open a pull request

Read [`CLAUDE.md`](CLAUDE.md): it lists the commands to run, the conventions the code follows, and
what counts as done, documentation included.
