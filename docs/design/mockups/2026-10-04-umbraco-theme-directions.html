Umbraco theme: three directions

The last mock was too subtle, so these three are meant to be seen from across the room. They share a kit, and each adds one idea of its own. The backoffice content is the same everywhere, because it is an iframe the theme never touches.

The shared kit

  • A round, Umbraco-ish control. The window buttons are 30px circles like the backoffice header apps, inside a 44px touch box. The close button is a soft danger wash with a danger glyph, and goes solid red only on press. Win11's square red slab is gone.
  • Cadet ink, not black. Titles use the interactive navy (#1b264f) instead of #060606, so the bold stays but stops feeling rough.
  • The focused window is unmistakable. It gets a coral tab-underline under its title, the same marker as the active section and the taskbar. The unfocused window turns sand and quiet instead of just fading.
  • 12px corners, the same radius as the cards inside the window, and a shadow tinted with the brand navy instead of neutral black.
  • The taskbar line is untouched. Only the hover changes: a rounded tile painted inside the same full-height button, so nothing gets smaller to touch.

Titlebar height stays 40px, so none of these change any window geometry. Only Mat does, by 6px of margin on three sides.

Close-up: attached windows

The docked pane header and the floating window's attached strip reuse the path-strip tokens, so they follow whichever direction is chosen. The strip and pane buttons are only about 20px tall today, which is too small for touch: they need the same invisible touch box as the window controls, and I have drawn it as the dashed boxes.

Touch sizes

ControlBeforeNew
Window buttons46 × 4044 × 40 touch box, 30px painted circleWidth meets 44. Height is the bar's 40; make the bar 44 if you want strict 44.
Taskbar buttonsfull bar height (50), 12px side paddingunchanged box, tile painted insideUnchanged
Pinned icon buttonsabout 42 wide44 wideMeets 44
Pane and strip buttonsabout 20px tall (2px 6px padding), width from its labelsame look, touch box grown to at least 44 wide and the strip's 28px high by an overlayNeeds the overlay; the strip itself cannot grow without costing content

Everything here is light mode. The new values are all rgba or color-mix of the navy, so they work on a dark backoffice too, but I have not drawn dark yet.
