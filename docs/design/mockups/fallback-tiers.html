How far should auto-discovery reach?

A

Sections only

Every registered section becomes an app (core + package). Cleanest, least noise — but a package that only adds a dashboard won't appear.

B

Sections + dashboards recommended

Sections plus each routable dashboard, badged by confidence. Catches most package functionality (many packages ship a dashboard, not a whole section).

C

B + an "Open any path" address bar

Everything in B, plus a power-user launcher where you type/paste any backoffice path and open it as a window. Ultimate escape hatch for the truly unregistered — always flagged ⚠.

I'd pick B as the default and keep C's address bar as a small power-user extra we can add cheaply. But if you want the escape hatch from the start, C is barely more work.
