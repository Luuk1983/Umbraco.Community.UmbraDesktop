A busy window says so on its own chrome

Issue #108. Fifty images dropped into a Media window: the window keeps working, and both its title bar and its taskbar button show how far the upload has got, so a minimized or buried window still says it is busy. Every theme draws the same element in its own idiom. Movement (the sweep, the stripes) is shown as a still.

The four states, in every row below

Known total14 of 50 files done. Draws as a proportion. Several uploads in one window are summed into one bar.
No known totalSomething is running and nobody knows how much is left. Activity, never a made-up percentage.
FailedThe bar stops where it failed and turns the danger colour. Stays while core still shows the failed files, then clears.
Busy and unsavedThe unsaved dot keeps its place beside the title. Progress lives somewhere else, so the two never compete.

Umbraco

Two candidates for the title bar. A is the base drawing every theme inherits: a 3px strip on the titlebar's bottom edge. B is a theme choice: the same element drawn as the window loader's turning ring, round the app icon. The ring overhangs the 16px icon by 4px into the gap that is already there, so it costs no width.
