The guidelines and what happens to each file

Three ways to show what the media guidelines are, without pills, each with a way to say what will happen to each file. The same six files in each: five ticked, tattoo-shop.jpg unticked. The site's upload limit is 15.4 MB, and team-day.png is over it.

A. A sentence, and the actions in words

The guidelines read as one sentence in a quiet box, named as the media guidelines. Each file says on the right what Optimize will do to it, in plain words with the guideline's icon.

  • In every variant the actions are what Optimize will do, not what is wrong: "Resize to 2560 px", "Convert to WebP", "Remove GPS location". A file over the upload limit that is resized or converted anyway gets nothing extra, since that already brings it under; one that is not says "Make it smaller than 15.4 MB".
  • An unticked file uploads as it is. A says so in words, B strikes its tags through, C strikes its cells through.
  • B's counts and C's columns grow with the guidelines: C needs a fourth column when a file is over the upload limit, and gets tight at 640 px with long Dutch headings.
