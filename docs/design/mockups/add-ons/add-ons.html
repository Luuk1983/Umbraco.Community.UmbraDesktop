UmbraDesktop Entertainment Add-on

by Luuk Peters
Version 17.4.0Umbraco 17 Free865 downloads

About

Games and media for UmbraDesktop. Minesweeper, Snake and Solitaire, and umbraCoffee, the Umbraco community's monthly live show, each in a window of its own on the desktop, themed along with everything else.

Install it and the launcher grows a Games group and a Media group. Open an app and it gets a window like everything else, in whichever theme you picked, so Minesweeper under the Windows 98 theme looks like Minesweeper, and under macOS it does not.

The full README from the Marketplace continues here.

Not on this site yet

Send this to whoever builds your site. After they deploy it, its apps appear in your launcher.

dotnet add package Umbraco.Community.UmbraDesktop.Entertainment --version 17.4.0

The version is the newest one that runs on Umbraco 17, which this site uses.

UmbraDesktop Accessories Add-on

by Luuk Peters
Version 17.4.0Umbraco 17 Free464 downloads

About

The small tools for UmbraDesktop. Notepad, Paint, Sticky Notes, Calculator, Character Map, Clock, Disk Cleanup and System Information, the ones Windows kept under Start > Programs > Accessories, each in a window of its own on the desktop, and a screen saver you set in Desktop settings.

Install it and the launcher grows an Accessories group. Open a tool and it gets a window like everything else, in whichever theme you picked, so Calculator under the Windows 98 theme has bevelled keys and under macOS it does not.

The full README from the Marketplace continues here.

Installed, version 17.4.0

Its apps are in your launcher. You are on the newest version for Umbraco 17.
