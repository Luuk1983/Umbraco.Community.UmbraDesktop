Welcome wizard

The first-run wizard from docs/design/2026-10-03-welcome-wizard-design.md, every page drawn as a still so nothing depends on scripts. It sits over the whole desktop on the boot screen's own dark ground, the same under every theme. The theme cards here are sketches; the real page uses the drawn theme previews the theme picker already has.

1. Welcome

It starts the way the boot screen looks: the mark with the arc turning. The arc closes into a full ring and Welcome fades in. About 2.5 seconds, then the language page appears by itself. A click or any key skips the wait.

2. Language

Every backoffice language, alphabetical, by its own name only. Where the desktop has no translation yet, the row ends in the desktop icon (the one on the header button that opens the desktop) and English. The subtitle says what that means, and hovering the mark says it again for that language; it is drawn open on Español here. The current language is selected, so the button reads Next. No Back on the first page.

Choose your language

The backoffice and the desktop use it. Where the desktop isn't translated yet, it shows in English. You can change this later in Desktop settings.

5. Open on sign-in, the last page

One switch, off. The button reads Done, because it finishes the wizard. Done saves everything in one go and fades the wizard out over the desktop in the chosen theme.

Start in the desktop?

Skip the classic backoffice and land straight on your desktop.

Open the desktop when I sign in

Takes effect the next time you open the backoffice. You can always change it in Desktop settings.

Things to look at
  • The main button never moves and is always filled: Next, Next, Done gets you through in three clicks on the same spot.
  • There is no Skip. Every page has a visible default, so going on with it is Next.
  • The dots sit centred on the button row rather than above it, which keeps the row as the one place to look.
  • Back is missing on the first page only.
