# Windows

- [Working with windows](working-with-windows.md): move, resize, maximise and close windows, and
  use the path under a window's title bar to go back.
- [Snapping](snapping.md): drag a window to an edge to give it half the desktop, or the whole of it.
- [Unsaved changes](unsaved-changes.md): how a window shows it holds unsaved work, and when the
  desktop asks before throwing it away.
- [Busy windows](busy-windows.md): how a window shows work that is still running, such as an upload,
  and when the desktop asks before stopping it.
- [Overwrite protection](overwrite-protection.md): what happens when someone else saves or deletes a
  document you have open. Plain Umbraco does not warn about this at all.
- [Live preview](live-preview.md): see the rendered page beside the editor, docked inside the same
  window or in a window of its own.
