# Snapping

- To give a window the left or right half of the desktop, drag it into that edge.
- To maximise a window, drag it into the top edge.

While the pointer is over an edge, an outline shows where the window will land. Let go to snap it
there.

To unsnap a window, drag it away from the edge. It returns to the size it had before.

The halves follow the desktop, so resizing the browser keeps them halves.

## On a narrow screen

Snapping respects each window's minimum size. If half the desktop is narrower than a window is
allowed to be, the window snaps to its own minimum instead, so on a narrow screen the two halves
overlap in the middle rather than one of them being squeezed too small to use. Selecting either
window brings it to the front. See [Screen size](../getting-started/screen-size.md).
