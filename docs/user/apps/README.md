# Apps

- [Background Jobs](background-jobs.md): every scheduled job Umbraco runs behind the site, with when
  it last ran and when it is due next. Umbraco shows this nowhere else.
- [Umbraco AI](umbraco-ai.md): the Copilot chat in a window beside your pages, with an agent that can
  open windows for you and read what is on your desk.
- [Commercial packages](commercial-packages.md): the apps you get for Forms, Deploy, Workflow,
  Commerce, Engage, UI Builder, Automate and Umbraco AI, and what happens to sections the desktop
  does not know.

Games are not part of this package. They come with the optional
[Entertainment add-on](https://www.nuget.org/packages/Umbraco.Community.UmbraDesktop.Entertainment),
which has documentation of its own.
