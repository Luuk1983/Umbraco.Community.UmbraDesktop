# Site

These settings are under **Site** in [Desktop settings](../settings/desktop-settings.md). They apply
to everyone on the site, not only to you, so only users with access to the Settings section can
see and change them.

- [Install as an app](install-as-an-app.md): install the backoffice as an app of its own, and give
  it the site's own name and icon.
- [Site name on the desktop](site-name-on-the-desktop.md): write the site's name in a corner of the
  desktop, so local, staging and production can be told apart.
