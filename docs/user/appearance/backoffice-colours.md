# Backoffice theme

"Theme" means two things here. The desktop's [themes](themes.md) restyle the chrome around the
windows. Umbraco's own, Light, Dark and High contrast, restyle everything, including the content
inside every window, and normally live in the user menu at the top of the backoffice.

**Backoffice theme** puts Umbraco's own choice beside the desktop's theme, under the name Umbraco
gives it. The two are told apart by the part of the screen they change: the desktop theme styles the
chrome around the windows, the backoffice theme everything inside them, which no desktop theme
touches.

## Change the backoffice theme

1. Open [Desktop settings](../settings/desktop-settings.md) and select **Appearance**.
2. Select the **Backoffice theme** row, under Theme and Wallpaper. The **Choose a backoffice theme**
   picker opens.
3. Select a theme. It applies straight away to the whole backoffice, and the picker stays
   open.

The list shows whatever themes the backoffice has registered, not a fixed three, because a
backoffice theme is an extension. A site that ships one of its own gets it here without doing
anything, and one that removes a shipped theme stops offering it.

It is one setting with two ways in. Set it here and the user menu agrees. Set it in the user menu and
this row updates while it is open. Either way the desktop repaints in the matching variant. The
explanation of what high contrast does to the chrome sits under this row.
