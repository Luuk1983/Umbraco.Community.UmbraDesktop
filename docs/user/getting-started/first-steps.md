# First steps

## Open the desktop

To open the desktop, select the desktop icon in the backoffice header, top right, between Help and
your avatar.

![The backoffice header, top right: the desktop icon sits between Help and the user avatar.](../../screenshots/header-entry-point.png)

The Desktop section's own tab in the section bar is hidden on purpose, so it does not clutter the
list. The header icon is the way in.

The first time, the desktop opens on a short [welcome wizard](welcome.md) that asks for your
language, a theme, and whether to open the desktop when you sign in.

To skip this step every time, turn on
[Open the desktop when I sign in](../settings/starting-in-the-desktop.md).

## Open an app

1. Select the launcher button on the taskbar. The launcher opens.
2. Select an app. It opens in a window of its own.

![The launcher: a search box, a Pinned row at the top, and every other app grouped by what it does.](../../screenshots/launcher.png)

Several apps can be open at once, and some of them, such as the Content editor and the Media
library, can be open more than once, so two documents can sit side by side. The windows contain the
backoffice you already know, with the same trees, editors and shortcuts.

## Open Desktop settings

To open Desktop settings, open the launcher and select the cog in its footer. The settings open as
a panel from the right, with the desktop in view behind it, so a change shows as it is made.
[Desktop settings](../settings/desktop-settings.md) lists what is in each category.

## Return to the classic backoffice

To leave the desktop, open the launcher and select **Exit desktop** in its footer, then confirm with
**Exit**. Open windows close, and the desktop asks first if any of them hold unsaved changes.

If the desktop is set to [open when you sign in](../settings/starting-in-the-desktop.md), exiting
keeps you in the classic backoffice until the tab is closed.
