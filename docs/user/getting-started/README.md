# Getting started

- [Installation](installation.md): install the package and grant the Desktop section to the user
  groups that should have it. Until that grant, nothing appears.
- [The welcome wizard](welcome.md): the three questions the desktop asks the first time you open
  it, and where to change the answers later.
- [First steps](first-steps.md): open the desktop, open an app, and find Desktop settings and the
  way back to the classic backoffice.
- [Screen size](screen-size.md): what to expect on a wide screen, a laptop and anything smaller.
